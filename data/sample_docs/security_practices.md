# Security Practices

All data at rest is encrypted using AES-256. Data in transit is encrypted using
TLS 1.2 or higher. Nimbus undergoes an annual third-party SOC 2 Type II audit.
Customer data is logically isolated per tenant; Business and Enterprise tiers can
additionally request single-tenant infrastructure isolation at extra cost.
Employee access to customer data requires multi-factor authentication and is
logged and reviewed quarterly.
