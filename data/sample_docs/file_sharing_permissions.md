# File Sharing and Permissions

Files and folders can be shared via link (view-only, comment, or edit) or
directly with specific email addresses. Link sharing can be restricted to users
within the organization's verified domain. Folder-level permissions cascade to
all contained files unless explicitly overridden at the file level. Business and
Enterprise tiers support granular role-based access control (RBAC) with custom
roles; Starter and Team tiers only support owner/editor/viewer roles.
