# Data Retention Policy

When a customer deletes a file, it is moved to a recoverable trash folder for 30
days before permanent deletion. When a customer cancels their account entirely,
all account data is retained for 90 days to allow for reactivation, after which
it is permanently and irreversibly deleted from all production and backup systems.
Deleted data is not recoverable after these windows under any circumstances,
including by Nimbus support staff.
