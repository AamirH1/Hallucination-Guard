# Account Deletion Process

To close an account, an admin must submit a deletion request from Account
Settings > Danger Zone, or email support. A confirmation email is sent and the
request must be confirmed within 7 days or it expires. Once confirmed, the
account enters the 90-day retention window described in the Data Retention
Policy before permanent deletion. During the 90-day window, a former admin can
request reactivation, which fully restores all data and settings.
